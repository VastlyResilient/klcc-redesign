## Evidence limits and implementation consequences

- Computed deltas between opening/middle/footer do not reveal easing, exact pin interval or whether an entrance is clock-driven versus scrubbed. Chosen sequences need deep dossiers before construction.
- Initial loads for Lou, Slab, Nouva, MVN and NetFolio were too early; delayed refreshed settled-opening states were captured. Initial loader frames are retained as behavior evidence, never treated as final composition.
- Lou pixelation is a source loading/transition treatment, not a reason to lower KLCC image quality.
- Current Slab Hydra shows image + title/Date/Location/Services metadata and cascading related-project imagery. The handoff example naming Overview/Challenge/Solution is not assumed true for this live revision.
- ConsultPro and Perform expose only one substantive inner route. Fragments is a marketing one-page template with a style-guide link. Portfoliod exposes no inner route. These cannot establish a complete inner-page world.
- No forms submitted and no source photography, trademarks or component code copied.
- Full route sets, HTTP status, screenshots and measured deltas are in `pool-discovery.json`, `pool-screening.json`, and `pool/<slug>/<route>/<viewport>/capture.json`.
